# VIREKA

Visual Integrity for Revenue & Expenditure Knowledge with Awareness

## Features

- Expense Management
- Income Tracking
- Budget Planning
- AI-powered Transaction Verification (Google Gemini)
- Financial Health Score
- Dashboard Analytics

## Tech Stack

- Laravel 11
- MySQL
- Tailwind CSS
- Chart.js
- Google Gemini API

```bash
composer install
npm install
cp .env.example .env
